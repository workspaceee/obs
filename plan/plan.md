# IMBA Widgets — оверлеи для OBS в стиле IMBA Cyber Club

Два виджета для стрима Dota 2. Первый — счётчик WIN / LOSE с серией, им управляют горячие клавиши прямо из игры. Второй — звание «текущее → цель»: медаль в рамке, неоновая стрелка, ещё одна медаль в рамке.
У каждого виджета своя постоянная ссылка и прозрачный фон. Всё настраивается в одной веб-панели.

## Для кого
Для стримера IMBA Cyber Club (Instagram @imba_cyberclub, TikTok @imba.cyber.club.kaunas), который стримит Dota 2 через OBS. Он хочет управлять оверлеями, не сворачивая игру, и показывать зрителям свою цель по званию.

## Основные функции и как это работает

### Виджет 1 — WIN / LOSE + серия
- Компактная плашка в кибер-стиле: острые срезанные углы, неоновые красные линии, белые акценты. Тёмная подложка есть только под самой плашкой.
- Показывает число побед (белый неон) и поражений (красный неон).
- Показывает текущую серию: «3 WIN STREAK» или «2 LOSE STREAK». Если серии нет, блок приглушён.
- Каждое изменение анимируется: цифра «перещёлкивается» с неоновой вспышкой. У WIN, LOSE и отмены свои эффекты.
- Три действия:
  - +WIN — добавить победу.
  - +LOSE — добавить поражение.
  - UNDO — отменить последнее действие. Можно нажимать несколько раз, тогда отменяются шаги по очереди.
- Запустить действие можно тремя способами: глобальной клавишей через помощник, кнопкой в панели или с телефона через ту же панель.

### Виджет 2 — Звание «текущее → цель»
- Отдельная постоянная ссылка, в OBS это отдельный Browser Source.
- Композиция: **[рамка с текущим званием] → [неоновая стрелка] → [рамка с целевым званием]**.
- Рамки в стиле оверлея IMBA: тёмные HUD-панели со срезанными углами, красная неоновая обводка, белые технические штрихи.
- Под каждой медалью подпись звания и количество звёзд, например «LEGEND ★★★», а над рамками ярлыки «CURRENT» и «GOAL».
- Стрелка анимирована: бегущие неоновые шевроны слева направо, медленная пульсация. Внимание привлекает, но не раздражает.
- Когда звание меняется, медаль проявляется с глитчем и красной вспышкой рамки.
- **Медали в высоком качестве с прозрачным фоном.** Картинки со скриншотов не используются, вместо них берутся оригинальные изображения медалей из игры:
  - все звания: Herald, Guardian, Crusader, Archon, Legend, Ancient, Divine;
  - у каждого 1–5 звёзд, всего 35 медалей;
  - плюс Immortal: обычный, Top 1000, Top 100, Top 10, Top 1.
- Для Immortal можно указать место в таблице лидеров. Оно выводится на золотой табличке под медалью, как в игре.
- Фон полностью прозрачный, вокруг медалей нет ни белых, ни чёрных квадратов.

### Программа-помощник для Windows (глобальные клавиши)
- Небольшой скрипт, который запускается перед стримом. Он ловит клавиши поверх Dota 2.
- Клавиши по умолчанию (стандартная раскладка Dota 2 их не использует):
  - Ctrl + Alt + Numpad 1 → WIN
  - Ctrl + Alt + Numpad 2 → LOSE
  - Ctrl + Alt + Numpad 0 → UNDO
- Клавиши меняются в веб-панели. Помощник сам подтягивает новые настройки, скачивать его заново не нужно.
- Помощник не трогает файлы и память игры. Он только отправляет команду на сервер виджетов.
- В трее показан статус: подключён или нет связи.

### Веб-панель настроек
- Тёмная панель в том же неоновом стиле. Вход по паролю, интерфейс на русском.
- **Вкладка «Счёт»:**
  - живой предпросмотр;
  - кнопки +WIN / +LOSE / UNDO;
  - ручная правка чисел;
  - «Сбросить счёт» (с подтверждением).
- **Вкладка «Звание»:**
  - выбор текущего и целевого звания из сетки медалей: звание + звёзды;
  - поле «место в топе» для Immortal;
  - кнопка «Поменять местами»;
  - живой предпросмотр.
- **Вкладка «Клавиши»:** нажимаешь «записать» и вводишь сочетание. Если клавиша уже занята другим действием, панель предупредит.
- **Вкладка «OBS»:**
  - две постоянные ссылки (счётчик и звание) с кнопками «Скопировать»;
  - рекомендуемые размеры Browser Source;
  - инструкция из 3 шагов;
  - скачивание помощника.
- Все настройки и состояние хранятся на сервере. После перезапуска ПК, OBS или панели ничего не теряется, ссылки не меняются.

## Сценарий использования
1. Стример входит в панель по паролю.
2. Копирует обе ссылки и добавляет их в OBS как два источника «Браузер». Это делается один раз.
3. Во вкладке «Звание» выбирает текущее звание, например Legend ★3, и цель, например Immortal.
4. Скачивает и запускает помощник, при желании меняет клавиши.
5. Запускает Dota 2 и стрим. После матча жмёт Ctrl+Alt+Num1 или Num2, и счёт с серией обновляется с анимацией. Ошибся — жмёт Ctrl+Alt+Num0.
6. Звание повысилось — меняет его в панели (можно с телефона), и виджет звания обновляется с эффектом.
7. Перед новым стримом сбрасывает счёт. Ссылки в OBS остаются те же.

## Внешний вид
- Стиль взят из рамки IMBA Cyber Club:
  - цвета чёрный, неоново-красный, белый;
  - геометрия «HUD» со срезанными углами;
  - тонкие светящиеся линии и мелкие технические штрихи.
- Шрифт широкий, гейминговый, цифры крупные, чтобы всё читалось даже на маленьком экране зрителя.
- Медали остаются в оригинальных цветах. Красный неон рамок их обрамляет, но не перекрашивает.
- Анимации короткие и чёткие: вспышка, глитч, свечение. Постоянно мигающего на эфире ничего нет.

## Этапы реализации

**Этап 1 — MVP (делаем сейчас)**
- Виджет WIN / LOSE + серия: прозрачный фон, анимации, постоянная ссылка.
- Виджет званий: рамка, медаль, стрелка, рамка, медаль. Все медали Dota 2 в высоком качестве с прозрачным фоном, постоянная ссылка.
- Веб-панель с паролем: управление счётом, выбор званий, настройка клавиш, ссылки для OBS, инструкция.
- Помощник для Windows с глобальными клавишами, которые не конфликтуют с Dota 2.

**Этап 2 — Улучшения оформления**
- Звуки на WIN / LOSE и повышение звания (по желанию, с регулировкой громкости).
- Варианты раскладки: счётчик горизонтальный, вертикальный или мини; звания в ряд или столбиком.
- Горячие клавиши для звания: +1 звезда, −1 звезда.
- Отдельная красочная анимация, когда текущее звание достигает цели.

**Этап 3 — Статистика и удобство**
- История матчей за стрим и автосброс счёта на новом стриме.
- Мобильная страница-пульт с крупными кнопками.
- Дополнительные виджеты в том же стиле (по запросу).

## Допущения (решено без отдельного вопроса)
- Виджет званий перенесён в MVP, потому что стример просил подготовить оба виджета сразу.
- Пользователь один: стример. Панель защищена одним паролем.
- Медали берутся из оригинальных игровых изображений Dota 2 (с вики Liquipedia) в максимальном доступном разрешении с прозрачным фоном. Если на выбранном размере они выглядят мягко, готовятся увеличенные чёткие версии. Изображения принадлежат Valve. На стримах их используют повсеместно, но они остаются игровыми ассетами.
- Звёзды показываются так же, как в игре, то есть уже встроены в саму медаль, и дополнительно подписью.
- Помощник работает на бесплатном AutoHotkey v2, его нужно один раз установить. Если в полноэкранной Dota клавиши не сработают, помогает режим «Полноэкранный в окне».
- Клавиши по умолчанию: Ctrl + Alt + Numpad 1 / 2 / 0.
- Серия — это победы или поражения подряд. После UNDO она пересчитывается.
- Счёт сам не обнуляется, только кнопкой в панели.
- Надписи на виджетах на английском (WIN, LOSE, STREAK, CURRENT, GOAL, названия званий).
- Логотип и соцсети в виджеты не встраиваются, они уже есть в основной рамке.
- Рекомендуемые размеры Browser Source: счётчик 600×200, звание 900×360. Виджеты масштабируются без потери качества.
