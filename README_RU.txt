IMBA WIDGETS - локальная версия для Windows 10 / 11
====================================================

ЧТО ЭТО
  Два виджета для OBS (счёт WIN/LOSE и звание текущее -> цель),
  веб-панель управления и горячие клавиши поверх Dota 2.
  Всё работает у вас на компьютере: http://127.0.0.1:8765

КАК ЗАПУСТИТЬ
  1) Распакуйте архив ЦЕЛИКОМ (правой кнопкой -> "Извлечь всё"), папку положите,
     например, на рабочий стол. Подходит и архив с GitHub (папка obs-main).
     Файлы .bat должны лежать в главной папке рядом с папками backend и windows.
  2) ПЕРВЫЙ РАЗ: двойной клик по  1_FIRST_START_INSTALL.bat
     - скачает портативный Python 3.12 и AutoHotkey v2 прямо в эту папку
       (в систему ничего не устанавливается, права администратора не нужны);
     - установит нужные библиотеки;
     - сразу запустит сервер, помощник клавиш и откроет панель в браузере.
     Нужен интернет, занимает 1-3 минуты.
  3) ДАЛЬШЕ (каждый стрим): двойной клик по  2_START.bat
  4) Остановить всё:  закрыть окно консоли, Ctrl+C или  3_STOP.bat

  Если Windows покажет "Система Windows защитила ваш компьютер" -
  нажмите "Подробнее" -> "Выполнить в любом случае" (файлы из интернета).
  Если брандмауэр спросит про доступ Python - разрешите для "Частных сетей":
  тогда панелью можно управлять с телефона по Wi-Fi.

ССЫЛКИ ДЛЯ OBS (Источник -> Браузер)
  Счёт:    http://127.0.0.1:8765/widget/score   ширина 600  высота 200
  Звание:  http://127.0.0.1:8765/widget/rank    ширина 900  высота 360
  Снимите галочки "Отключать источник, когда он не виден" и
  "Обновлять браузер при активации сцены". Фон уже прозрачный.

ПАНЕЛЬ
  http://127.0.0.1:8765/panel     пароль по умолчанию: imba2025
  (поменять: вкладка OBS -> "Сменить пароль")
  Совет: в OBS -> Док-панели -> Пользовательские браузерные док-панели
  добавьте ссылку на панель, и кнопки WIN/LOSE будут прямо в OBS.

ГОРЯЧИЕ КЛАВИШИ (по умолчанию)
  Ctrl + Alt + Num 1  -> +WIN
  Ctrl + Alt + Num 2  -> +LOSE
  Ctrl + Alt + Num 0  -> UNDO (отменить последнее)
  Поменять: панель -> вкладка "Клавиши". Помощник подхватит сам.
  Значок помощника (AutoHotkey) в трее показывает статус подключения.
  Если в полноэкранной Dota 2 клавиши не срабатывают - включите режим
  "Полноэкранный в окне" (Borderless).

ГДЕ ДАННЫЕ
  data\imba-db.json - счёт, звания, клавиши, пароль. Сохраняется между запусками.
  Чтобы обновить программу - замените папки backend и windows и файлы .bat,
  папку data оставьте.

СТРУКТУРА ПАПКИ (не перемещайте файлы!)
  1_FIRST_START_INSTALL.bat  2_START.bat  3_STOP.bat  README_RU.txt
  backend\            сервер (server.py, storage.py, helper_script.py)
  windows\scripts\    скрипты установки и запуска + messages.ru.json
  windows\web\        готовые виджеты и панель
  runtime\            появится после установки (Python, AutoHotkey)
  data\               появится после запуска (счёт, настройки, server.log)

ЕСЛИ ЧТО-ТО НЕ ТАК
  - "Порт 8765 занят" -> запустите 3_STOP.bat, затем 2_START.bat.
  - Сломалась установка -> удалите папку runtime и снова 1_FIRST_START_INSTALL.bat.
  - Лог последнего запуска: data\server.log
